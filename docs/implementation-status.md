## 1.1.0 統合済み: 方向拘束監査の独立した公開限定機能

`direction-binding public slice・245dad95-accf-581c-8b0a-ae1c1f557de4` は、マージコミット
`a77c3cbdc69295572e90333e2a6e9da690fbbb6d` が拘束する正式な 1.1.0 ソースコードへ
選択統合した別の対象である。ソースコードには `semantic-guard-direction-binding-audit/v1`、
CLI `audit-direction-binding`、MCP `audit_direction_binding_tool` 及び項目を限定したスキーマ

監査の一次判断は、同一対象・同一操作について、方向を未指定のままにする表現へ、方向を
限定する表現が直接結び付いているかである。尺度系の `decision-frame-summary/v3` と六軸の非尺度系
`direction-binding-summary/v1` は主判定を出せる範囲を分け、形態素解析は `signal_only`、数値は
任意の影響証拠に限る。方向選択、一般自然言語理解、実務妥当性及び人間受理はこの
ローカル契約に含めない。

五ファイルだけを選択する `derived_from` とし、
[ソース対応表](../migration/direction-binding-source-map-2026-08-23.json) にハッシュ値と

## 独立査読で見つけ、修正した誤通過

- 同じ人間判断を内容変更後の行為・妥当性・責任方針へ再利用できた。
- 同じ人間受理記録を相反する状態評価へ再利用できた。
- 局所試験を`validation=supported_in_context`へ申告だけで昇格できた。
- `before=unresolved / after=unresolved`でも`effect=resolved`と書けば修復全体を`improved`にできた。
- 安全運用で後発廃止、自己観測による成功扱いへの置換、公開資料の合成扱い、再起動差替え、証拠種別差替え、保持証拠欠落を通せた。
- 人間利用評価で人間だけが行える判断の禁止集合を削り、修復軸だけで受理権限を不正に上げられた。
- 評価方針の基準・候補と課題材料を無関係に差し替え、同一材料でも比較成立にできた。
- 同一参加者の反復を独立標本として数え、未観測参加者を分母から落とせた。
- 後発の方針廃止、基準側の脱落超過、未評価の役割、移譲先 `no_action`、修復成果物の自己検証及び観測時刻と経過秒の不一致を残したまま成果評価を肯定できた。
- 入れ子が深すぎる入力や要素数が多すぎる入力、非 JSON 数値、一軸欠落により、構造化したエラーではなく未処理例外を発生させられた。
- `wheel` 外の紛らわしい隣接 `schemas/` 又は `validation/` が、同梱契約を背後で差し替えられた。

各反例は v1/v2 契約又は敵対試験へ追加し、ローカル検査で通過しないよう修正した。配布物は
パッケージ資源を先に解決し、ソースコードへの代替経路はソース配置が一致する場合だけ許可するようにした。これらは、試験数より
試験範囲の完全性が重要であることを示す。

## 未成立の証拠・統合項目

1. **規範採択** — 規則パックと十工程プロファイルを領域専門家と人間の担当者が査読・採択する。
2. **一貫統合** — ライフサイクルプロファイルの解決器、プロファイル適合変換器、状態・行為・修復・評価の失効伝播、CLI/MCP入口を実装する。
3. **実務資料評価** — 対象母集団、重大な偽充足の費用、閾値、独立した二重ラベル付け、保留標本、除去比較を人間方針へ結んで実行する。
4. **行為・真正性連携** — 実行時事象、主体・権限の時点記録、署名検証、信頼時刻、外部台帳、成果物の来歴を取得する。
5. **人間利用評価** — 実参加者、真正な同意、独立盲検採点、脱落を含む実務調査を実行する。
6. **運用適格性** — 実配備で長時間、並行、負荷、枯渇、解析提供者障害、再起動、復旧、互換、事故を測る。
7. **外部移行判断** — 外部配備は観測運転、明示選択、巻戻し予行、証拠移行を経て、人間が既定化又は旧系廃止を別々に判断する。
