# 修正の循環と責任分担の判断材料

記録日: 2026-07-16
状態: 明示的に有効化する独立契約。実務上の効果、人間の理解、受理は未評価

## 目的

この契約は、監査所見を「直すべき対象」へ結び付け、外部で行われた変更を再監査し、所見の解消、回帰、未解決事項、移譲を別々に記録する。また、コーディングエージェントが処理できる技術作業と、人間しか決められない意図、危険の受容、権限、最終受理を一つの出力へ混ぜない。

実装対象は次の三契約である。

```text
responsibility-policy/v2       人間が管理する役割・判断権・効果判定方針
          ↓
responsibility-material/v0     エージェント向け修復材料又は人間向け判断材料
          ↓
repair-cycle/v2                所見→外部変更→再監査→局所効果比較
```

正式な機械契約は `schemas/responsibility-policy.schema.json`、`schemas/responsibility-material.schema.json` 及び `schemas/repair-cycle.schema.json` であり、本文書は意味の境界と項目間の検査を説明する。

これは修正の実行器でも作業管制でもない。優先度、委譲、実行、質問の送信、危険の受容、最終受理は外部に残る。

## 責任方針

`responsibility-policy/v2` は、役割、実行主体の区分、判断権、問題区分ごとに責任を負う役割、担当を許される役割、必要な判断権、先に行える技術作業、移譲条件、修正効果の方針を版とハッシュ値へ結び付ける。v2 は、採択判断を行う人間主体の同一性固定を必須にした破壊的契約変更であり、v0 及び v1 の方針を暗黙には受理しない。

`adopted` には外部人間判断記録が必須である。判断記録は `decision_kind=adopt_responsibility_policy`、方針 ID、版、`policy_basis_digest` を完全一致で指す。`decided_by` は、版と内容ハッシュ値を持つ `decision_maker_identity` と同一 ID で、`decision_maker_kind=human`、`external_to_semantic_guard=true`、`status=accepted`、外部記録の所在及びハッシュ値を必須とする。判断主体がエージェント種別であるか、`decided_by` が `decision_maker_identity.entity_id` と一致しない判断は拒絶する。基礎ハッシュ値は、採択状態・判断記録・最終ハッシュ値を除く意味内容から先に計算するため循環せず、役割、判断権又は効果方針を変えた記録へ古い採択判断を使い回せない。`pending` 又は `retired` から利用材料は作らない。コーディングエージェント、自動処理又は作業管理側には、次の人間だけが持つ判断権を与えられない。

- 意図又は範囲の変更
- 残余危険の受容
- 権限の付与又は拡張
- 外部作用の許可
- 最終受理

この制約は、成功した実行や技術的な通過から権限がさかのぼって付与されることを防ぐ。方針記録の存在、署名者の本人性、組織上の妥当性は別途検証を要する。

## 役割別材料

`responsibility-material/v0` は、同じ監査内容を一つの万能文章へ潰さず、次のどちらかとして出す。

### コーディングエージェント向け

- 観測事実、根拠、限界及び未解決範囲
- ハッシュ値付きの修正対象と所在
- 欠陥に関する仮説と意図する効果
- 成功条件、回帰防護及び停止条件
- 現在の役割で候補にできる作用
- 人間だけが行える判断の禁止と移譲条件

修正対象には `finding_suppression_is_not_repair` と `changed_output_without_reaudit_is_not_success` を必須とする。警告文を消す、規則を弱める、出力が変わっただけで成功とする、といった中身のない変更を修正へ数えないためである。

### 人間向け

- 観測事実、根拠、限界及び未解決範囲
- 決めるべき一つの命題
- 必要判断権
- 二つ以上の選択肢と、それぞれ異なる便益と危険
- 停止及び再検討条件

材料内に決定値は持たせない。監査器が `accept`、`request_revision` 又は `defer` を先回りして埋めれば、人間判断の境界を破るからである。監査器は材料を宛先へ送信せず、外部呼出元又は作業管理側が扱う。

## 修正の循環

`repair-cycle/v2` は次の監査入力を、一つの修正循環記録へ結び付ける。v2 は、修正効果について査読対象を固定するハッシュ値と、型付きの独立査読記録を必須にした破壊的変更であり、v0 及び v1 は暗黙に受理せず、再作成を要する。

1. 対象と変更前監査の ID・ハッシュ値。
2. 各所見の義務、変更前結果、根拠、限界、修正対象及び責任材料。
3. 外部で行われた変更の実行主体、同一性証拠、権限証拠、時刻、変更前後の対象ハッシュ値、変更証拠、停止条件の結果。
4. 別個の変更後監査、全所見の前後比較、全回帰防護、移譲結果、独立査読参照及び残る未解決事項。

各所見結果は、変更後監査、変更後対象のハッシュ値、義務 ID、結果値、結果の所在、結果のハッシュ値を持つ型付き `after_audit_result_ref` へ結び付ける。各回帰結果も同様に、変更後監査、変更後対象、回帰防護 ID、結果値、元の結果を `execution_result_ref` へ結び付ける。型付き結果の ID とハッシュ値は、各証拠参照集合にも存在しなければならない。

`repair_attempt` の存在は成功を意味しない。変更後監査が無い間は `not_assessed` のままであり、自己申告しかない解消、変更前監査の再利用、所見又は回帰防護の欠落、変更前結果のすり替えを拒否する。

個別の `effect` は呼出元が自由に決める値ではない。`repair-effect-transition/v1` が変更前後の結果から導出し、矛盾する申告を拒絶する。変更後が `supported` なら `resolved`、前後同値なら `unchanged`、変更後が `refuted` 又は `invalid` へ悪化した場合は `worsened`、比較不能又は未知は `unknown` とする。局所総合結果は、導出済みの個別効果から次の保守的規則で導出する。

| 条件 | 局所結果 |
| --- | --- |
| 全所見解消、全回帰通過、移譲漏れなし、対象ハッシュ値変更 | `improved` |
| 解消と未解決・未知・悪化が混在 | `mixed` |
| 悪化、回帰失敗、停止違反又は必要移譲漏れのみ | `regressed` |
| 全所見不変かつ全回帰通過 | `no_change` |
| 証拠未知又は対象不変のまま解消を主張 | `indeterminate` |

いずれも `claim_scope=declared_local_reaudit_only` であり、`field_repair_effect=not_evaluated` は固定される。実務でエージェントの修正成功率が上がるか、所要時間、回帰率、移譲精度、人間の理解が改善するかは、独立した現場評価の命題である。

責任方針の `independent_review_required=true` では、評価済み循環に一件以上の `repair-independent-review/v1` 記録を必須とする。記録は、人間査読者の ID・版・ハッシュ値、`relationship_to_subject=independent`、`external_to_semantic_guard=true`、循環 ID と修正試行を含む非循環の `cycle_basis_digest`、変更後監査参照、査読対象の `effect_basis_digest`、`status=accepted`、RFC 3339 の時差付き査読時刻、一件以上の証拠参照、外部記録の所在・ハッシュ値、記録全体のハッシュ値を結び付ける。単なる `{entity_id, entity_digest}`、空配列、全零ハッシュ値、別循環、別の変更後監査、別の効果ハッシュ値、非人間又は非独立の査読者は要件を満たさない。

`effect_basis_digest` は、査読記録自体を除いた所見比較、回帰結果、移譲結果、局所総合結果、残る未解決事項、限界を対象に先に計算する。その後に外部査読記録を結び付けるため循環しない。査読記録の `authenticity_status` は `unverified` 固定であり、記録内部の構造・参照・ハッシュ値の一致を超える査読者の実在、組織上の独立性、署名、内容の真正性は依然として外部証明を要する。

## 検証済みの失敗経路

- 未採用方針からの材料生成
- 人間判断権を持つコーディングエージェント
- 必要な判断権を持たない責任者
- 人間判断の代行を禁止していないエージェント向け材料
- 外部又は不可逆作用を「利用可能な作用」とする監査出力
- 方針と異なる人間質問
- 抜け道を防ぐ条件の消失
- 責任材料の差替え
- 変更だけを修復成功とする評価
- 変更前監査を変更後監査として扱うこと
- 自己申告だけの所見解消
- 所見又は回帰防護の欠落
- 変更前結果及び総合結果の不当な書換え
- `unresolved` のまま `resolved` とする個別効果のごまかし
- 変更後監査・対象・義務・回帰防護・結果値の参照すり替え
- 方針が要求する独立査読の欠落
- 単なる参照又は全零ハッシュ値による、独立査読の中身のない形式化
- 非人間又は非独立の査読者、別循環、別の変更後監査、別の効果ハッシュ値への査読すり替え
- 変更済み責任方針への採択判断再利用

## 残余危険

- 人間が管理する方針について、判断主体の同一性は記録内部で固定するが、実人物との対応、組織上の妥当性、権限記録、署名、本人性は未立証である。
- 修正の実行主体、権限証拠、時刻、変更証拠、再監査証拠の真正性は、各 `repair-cycle` 記録の内容ハッシュ値だけでは立証できない。
- 対象の所在と実際の編集範囲が一致するかの確認には、実在する成果物を読み取る接続処理が必要である。
- 局所再監査が通っても、実務上の対象集団における修正効果、理解可能性、組織への適合性は未評価である。
- semantic-guard は修正を実行せず、作業管理側の優先度・配員・順序を決めず、人間へ質問を送らない。
